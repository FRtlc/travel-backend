游指南 隐私政策

更新日期：2026年8月1日

游指南（以下简称"本应用"）非常重视用户隐私。本隐私政策说明本应用在收集、使用和保护用户信息方面的做法。请您在使用本应用前仔细阅读本隐私政策。

一、我们收集的信息

本应用在运行过程中可能收集以下信息：

  • 位置信息：当您使用"附近景点"或导航功能时，本应用会请求获取您的地理位置（GPS），用于计算您与景点之间的距离和推荐附近景点。位置信息仅在本地使用，不会上传到服务器。
  • 用户打卡数据：您在景点的打卡记录、评论和评分保存在本地设备上，如果您登录了账号，这些数据会同步到云端以便跨设备使用。
  • 设备信息：应用版本号、操作系统类型（用于检查更新和兼容性判断）。

二、信息的使用

我们收集的信息仅用于以下目的：

  • 提供景点推荐、附近景点排序和导航功能
  • 保存和管理您的打卡记录和个人数据
  • 检查应用更新，推送新版本通知
  • 改进应用功能和用户体验

三、第三方 SDK 说明

本应用使用了以下第三方 SDK，各有其独立的隐私政策：

  • Capacitor Geolocation：用于获取设备 GPS 位置，仅在用户主动使用相关功能时调用，不会后台持续定位。
  • Capacitor Browser：用于在外部浏览器中打开购票、酒店预订等第三方链接。
  • Capacitor Haptics：用于触觉反馈（震动），不涉及数据收集。

本应用不集成任何广告 SDK，不包含广告推送功能。

四、信息的存储与保护

  • 位置信息仅在设备本地处理，不会上传至服务器。
  • 用户账号数据通过加密传输存储在云端服务器，使用安全的通信协议。
  • 本应用采用 electron-updater 进行版本更新检查，更新文件通过 GitHub Releases 分发并经过 SHA-512 校验。

五、信息的共享与披露

我们不会将您的个人信息出售、交易或出租给第三方。在以下情况下，我们可能会披露您的信息：

  • 获得您的明确同意
  • 根据法律法规要求或政府主管部门的命令
  • 为保护本应用、用户或公众的合法权益

六、用户权利

您拥有以下权利：

  • 访问权：您可以随时查看您的打卡记录和个人数据。
  • 删除权：您可以在应用设置中清除本地数据，或联系我们删除云端数据。
  • 撤回同意权：您可以在系统设置中随时关闭位置权限，不影响应用其他功能的使用。
  • 卸载权：卸载应用后，本地数据将自动删除。

七、未成年人保护

本应用面向所有年龄段的用户，不专门针对未成年人。如果您是未成年人的监护人，发现任何不适内容请及时联系我们。

八、隐私政策的更新

我们可能会不时更新本隐私政策。更新后的隐私政策将在本页面发布，并以应用内通知的形式告知您。继续使用本应用即表示您同意更新后的隐私政策。
